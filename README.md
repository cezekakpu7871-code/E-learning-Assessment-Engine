# E-Learning Online Assessment Engine

An automated test evaluation system built in Python designed to grade digital multiple-choice assessments and issue cryptographically hashed completion signatures (SHA-256) for grade verification. Enforces software engineering design patterns for academic platform integrations.

## Extended Description
An automated test evaluation system built in Python designed to grade digital multiple-choice assessments and issue cryptographically hashed completion signatures (SHA-256) for grade verification. Enforces OOP design patterns for academic platform integrations.

## Core Features

- **Automated Grading:** Computes percentage scores across dynamic question sets instantly.
- **Certificate Fingerprinting:** Generates unique SHA-256 result fingerprints to prevent grade forgery.
- **Academic Platform Integration:** Modular object-oriented architecture designed for higher education environments.
